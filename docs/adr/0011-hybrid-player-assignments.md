# Keep Player Assignments optionally structured

Chalk uses a hybrid Assignment model that preserves a Coach's exact language while allowing structured football actions where they improve diagrams, animation, and generated position materials. A Play can be saved without complete or structured Assignments.

## Consequences

- Each Player may own a concise Coach-written Assignment.
- An Assignment may contain ordered structured actions for movement, blocking, coverage, pressure, handoff or fake behavior, kicking, or other diagram behavior.
- Structured actions may reference MovementPaths, Players, landmarks, or zones.
- Structure is progressive: Coaches can add only freeform text, only diagram actions, both, or neither.
- Freeform arrows, shapes, and notes may remain unattached annotations when they do not represent a Player's Assignment.
- Position sheets combine the Coach's exact wording with the relevant Player and diagram context.
- Beta never requires every Player to have an Assignment or every Assignment to use a predefined action type.
